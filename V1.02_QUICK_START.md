## 🎯 How It Works Now

### Entry Logic
```
1. Check H1 trend (EMA alignment) ✓
2. Check if trading session allowed OR strong trend ✓
3. Wait for M15 entry signals (MA + MACD + RSI) ✓
4. Open position with NO stop loss ✓
```

### Exit Logic (Manual - Automatic)
```
Position exits when ANY of these occur:

1. Opposite signal detected
   - Buy exits when SELL signal appears
   - Sell exits when BUY signal appears

2. Price crosses 21 EMA opposite direction
   - Buy exits when price crosses below 21 EMA
   - Sell exits when price crosses above 21 EMA

3. H1 trend changes (optional - disabled by default)
   - Buy exits when H1 becomes bearish
   - Sell exits when H1 becomes bullish
```

### Session Filter + Strong Trend Override
```
IF ADX >= 25 (Strong Trend):
    → Trade ANYTIME (24/7)
    → Session filter BYPASSED
    → Captures all major trending moves

ELSE (No Strong Trend):
    → Only trade during London or NY sessions
    → Wait during Asian session
    → Safer, lower volatility times
```

## ⚠️ CRITICAL WARNINGS

### 1. NO STOP LOSS = UNLIMITED RISK
- A single trade can cause **massive losses**
- News events (NFP, FOMC) extremely dangerous
- Weekend gaps can be catastrophic
- **MUST test on demo account first**

### 2. Manual Exits Check Every M15 Bar
- Exit conditions evaluated every 15 minutes
- Fast moves may cause large losses **before** exit triggers
- Not instant like a hard stop loss

### 3. Circuit Breaker Disabled by Default
- EA will **never stop trading** automatically
- Can lead to **complete account loss**
- **Strongly recommend** keeping it enabled at 15-20%

### 4. Session Times Are GMT
- Verify your broker's server time offset
- London: 08:00-17:00 **GMT** (not your local time)
- NY: 13:00-22:00 **GMT**
- Asian: 00:00-09:00 **GMT**

### 5. Strong Trend Override Bypasses All Filters
- When ADX >= 25, trades **anytime**
- This is intentional (catches big moves)
- But also trades during news, gaps, etc.

## 🆘 Emergency Actions

### If Position Going Against You:
1. **Manual close** in MT5 (EA won't interfere)
2. **Enable SL:** Set `Use_Stop_Loss = true`, restart EA
3. **Enable circuit breaker:** Set `Enable_Circuit_Breaker = true`
4. **Disable EA:** Click AutoTrading button OFF

### If Too Many Losing Trades:
1. Increase `Strong_Trend_ADX_Level` to 30-35
2. Enable `Exit_On_Trend_Change = true`
3. Reduce `Fixed_Lot_Size` to 0.01
4. Enable `Use_Stop_Loss = true` (safety net)

### If No Trades At All:
1. Check `Enable_Debug_Logging = true`
2. Verify session times match broker GMT offset
3. Check if `Strong_Trend_ADX_Level` too high
4. Disable `Use_Session_Filter = false` temporarily
5. Review debug logs for reason
