### 3. **DAILY LOSS LIMIT** ✅ (NEW)
```
Enable_Daily_Loss_Limit = true
Max_Daily_Loss_Percent = 2.0%
```

**What it does:**
- Tracks daily equity from start of day
- If daily loss reaches 2% → **STOPS TRADING**
- Resets at midnight (new trading day)
- Prevents catastrophic daily losses

**Example:**
```
Day starts: $10,000
Trade 1: -$100 (1% loss)
Trade 2: -$120 (1.2% loss, total 2.2%)
→ LIMIT HIT: "⚠️ DAILY LOSS LIMIT HIT - No more trading today!"
```

### 8. **EQUITY-BASED POSITION SIZING** ✅ (NEW)
```
Automatic reduction during drawdown
```

**What it does:**
- If account is in drawdown → **reduces position size**
- 5% drawdown → 5% smaller positions
- 10% drawdown → 10% smaller positions
- Never goes below 50% of normal size
- Helps recovery by taking less risk

**Example:**
```

10% drawdown ($9,000) → 0.18 lots (10% reduction)
```
